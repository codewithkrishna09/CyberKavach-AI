How the Interceptor Works

Traditional antiviruses scan URLs against slow cloud blacklists. The CyberKavach Chrome Extension lives natively inside your browser, dissecting HTML structures as they download.

Pre-DOM Isolation

We hook into the browser's webRequest API. Before the browser even paints the pixels on your screen, our extension parses the HTML input fields looking for credential harvesters.

Captcha Evasion Defeat

Scammers hide behind Cloudflare Turnstiles so Google bots can't scan their phishing page. Since our extension sits behind the captcha wall with you, it catches the threat perfectly.

Zero-Log Encryption

When checking a URL against our master database, the extension creates a mathematical hash of the link. We never transmit or log your actual browsing history to our servers.

// Intercept all main-frame requests before they render
chrome.webRequest.onBeforeRequest.addListener(
  async function(details) {
    const targetUrl = details.url;
    
    // Send to local heuristic engine & Titan Backend
    const verdict = await CyberKavachAPI.scan(targetUrl);
    
    if (verdict.isThreat) {
      // Instantly freeze page & inject Warning DOM
      return { cancel: true }; 
      chrome.tabs.update(details.tabId, { url: "warning.html?ref=" + targetUrl });
    }
  },
  { urls: ["<all_urls>"], types: ["main_frame"] },
  ["blocking"]
);
